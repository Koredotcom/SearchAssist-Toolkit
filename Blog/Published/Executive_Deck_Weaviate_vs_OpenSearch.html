Future Roadmap - Dual Engine Strategy

📌 Current Approach

We begin with OpenSearch as the default enterprise search engine for all customers, ensuring robust reliability, mature search features, and enterprise-grade security out of the box.


At the same time, we provide self-hosted Weaviate as an option, primarily for advanced use cases requiring pure vector search, while offering a curated set of features to reduce complexity and operational overhead.

🚀 Future Direction

Adopt a hybrid model using both OpenSearch and Weaviate:

  • Weaviate: Dedicated to pure vector search, RAG workflows, and graph-based capabilities
  • OpenSearch: Handling enterprise-grade features (RBAC, ABAC, encryption, auditing, compliance)

✅ Benefits of Dual Strategy

  • Best of both worlds: Enterprise security + advanced vector/RAG
  • Scalable with smaller Weaviate pods
  • Reduced operational complexity
  • Future-proof with evolving RAG capabilities

⚠️ Considerations

  • Integration overhead between two systems
  • Requires orchestration layer for query routing
  • Monitoring & observability across dual stack

Balanced Future State

Leverage OpenSearch for enterprise compliance and Weaviate for cutting-edge vector + RAG — ensuring scale, security, and innovation together.

Infrastructure Requirements - Objective Analysis

☁️ Cloud Deployment

OpenSearch:
  • AWS managed service available
  • Higher costs for managed option
  • Excellent integration with AWS ecosystem
  • Auto-scaling capabilities
Weaviate:
  • Weaviate Cloud Services (WCS)
  • More cost-effective for pure vector use
  • Multi-cloud flexibility
  • Simpler pricing model

🏢 Private VPC

OpenSearch:
  • Mature VPC integration
  • Complex networking setup
  • Extensive security controls
  • Higher operational overhead
Weaviate:
  • Kubernetes-native approach
  • Simpler container deployment
  • Good isolation capabilities
  • Easier to manage in containers

🏭 On-Premise

OpenSearch:
  • Full control and customization
  • Complex cluster management
  • Requires Elasticsearch expertise
  • Higher infrastructure costs
Weaviate:
  • Simpler Docker/K8s deployment
  • Lower hardware requirements
  • Easier maintenance
  • Better resource efficiency

🏗️ Infrastructure Reality

OpenSearch offers more mature enterprise features but requires more infrastructure expertise and resources. Weaviate provides simpler deployment but may require more custom development for complex enterprise requirements.

Operational Complexity - Realistic View

✅ OpenSearch Operational Profile

  • Managed: AWS handles infrastructure (premium cost)
  • Self-managed: Requires Elasticsearch expertise
  • Tooling: Mature ecosystem and monitoring
  • Documentation: Extensive enterprise guides
  • Support: Enterprise support available
  • Complexity: High for self-managed, medium for managed

✅ Weaviate Operational Profile

  • Deployment: Simpler container-based setup
  • Management: Requires complex application management
  • Scaling: Straightforward horizontal scaling
  • Monitoring: Basic but improving tools
  • Support: Growing enterprise support
  • Complexity: Medium for all deployment models
  • Challenge: Too much of application orchestration needed

Scaling Characteristics

📈 Horizontal Scaling

OpenSearch: Complex shard management, rebalancing challenges, potential performance impacts during scaling

Weaviate: Simpler pod-based scaling, more predictable resource requirements, easier to automate

📊 Vertical Scaling

OpenSearch: Requires careful planning, rolling restarts, potential downtime

Weaviate: More flexible resource adjustments, container-native scaling

🌍 Multi-Region

OpenSearch: Built-in cross-region replication, mature disaster recovery, complex setup

Weaviate: Manual multi-cluster setup, simpler architecture, requires custom coordination

🔄 Data Migration

OpenSearch: Mature migration tools but complex for large datasets, version compatibility issues

Weaviate: Simpler data models but limited migration tooling, manual processes required

📈 Scaling Trade-offs

OpenSearch provides more enterprise scaling features but with higher complexity. Weaviate offers simpler, more predictable scaling but may require custom solutions for complex enterprise scenarios.
